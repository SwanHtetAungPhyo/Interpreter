## 🧠 Interpreter

A basic interpreter built with a lexer and parser, capable of performing fundamental operations.

### 🔍 What I Learned

- Gained a solid understanding of how **lexers** and **parsers** work together in language processing.
- Learned how to implement a **custom lexer** using **ANTLR4**, which brought this interpreter to life.
- Discovered how parsing rules and grammar can be designed to evaluate simple expressions and statements.

This project gave me hands-on experience with core concepts behind compilers and interpreters, and serves as a foundation for building more advanced language tools.
